# Genwilliam Tap

## How do I install these formulae?

`brew install genwilliam/tap/<formula>`

Or `brew tap genwilliam/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "genwilliam/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
